Methodology & provenance

Evidence before confidence.

What the numbers mean

NASA mode uses apparent airless body-center elevation (with light-time and aberration corrections). Visibility uses body-center elevation strictly above the chosen threshold. Fractions are time-weighted using the state at the start of each interval. The final sample closes the window. Irregular or coarse sampling can miss crossings and short outages.

What is not modeled

The flat-reference analysis excludes terrain; the separate LOLA terrain study supports covered custom coordinates through the local server and retained DEM, with four precomputed profiles in the portable edition. No solar disk, power budget, antenna link budget, relay availability, thermal model or uncertainty propagation. Imported values are user supplied and not independently verified. This is not an operational planning tool.
